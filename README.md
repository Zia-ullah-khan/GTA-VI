# GTA-VI

Research notes and derived data for GTA VI (Xbox build v1.0.2.1).

## Contents

- `GTAVI v1.0.2.1 Knowledge Dossier.md`: the knowledge dossier, with the mission table and routing notes.
- `vehicles/`: vehicle performance figures, the special-spawn list, and a ranked report built from them.
  - `fastest-vehicles.md`: the fastest road vehicles, placed spawns, and the best car in each area.
  - `vehicle-spawns.csv`: every special spawn, with its area, kind and performance figures.
  - `vehicle-performance.csv`: performance figures for all 251 vehicles.

## What is not here

The game's own files are not in this repository. That means no decompiled scripts, no raw archive
contents, and no game text or dialogue. The tables here are derived from the game data, and
descriptions taken from the game's text have been left out.

This is an unofficial research repository. It is not affiliated with or endorsed by Rockstar Games
or Take-Two Interactive.
