### 1. Typical C / C++ or Rust Header Layout (`RPF7` / `RPF8`)

In open-source tooling (such as CodeWalker[3], community documentation[2], or Rust libraries like `rpf-archive`[1]), the root header layout maps conceptually to a structure like the following:

```c
struct RpfHeader {
    uint32_t magic;           // "RPF7" (0x37465052) or "RPF8" (0x38465052)
    uint32_t entryCount;      // Total number of file and directory entries
    uint32_t namesLength;     // Size of the string blob for file/dir names (absent/0 in some RPF8 implementations)
    uint32_t encryptionType;  // 0 = None, OPEN (0x4E45504F), AES, or NG
};
```[4][2]
